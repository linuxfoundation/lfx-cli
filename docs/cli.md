# NAME

lfx - Authenticate with and call the LFX platform APIs

# SYNOPSIS

lfx

```
[--help|-h]
[--version|-v]
```

**Usage**:

```
lfx [GLOBAL OPTIONS] [command [COMMAND OPTIONS]] [ARGUMENTS...]
```

# GLOBAL OPTIONS

**--help, -h**: show help

**--version, -v**: print the version


# COMMANDS
